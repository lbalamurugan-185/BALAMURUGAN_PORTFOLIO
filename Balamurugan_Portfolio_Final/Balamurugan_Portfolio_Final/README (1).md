## 🌍 Deployment

This portfolio can be deployed using **GitHub Pages**.

### GitHub Pages Steps

1. Push the project to GitHub.
2. Open the repository.
3. Go to **Settings**.
4. Select **Pages**.
5. Choose **Deploy from a branch**.
6. Select:
   - Branch: `main`
   - Folder: `/ (root)`
7. Click **Save**.

Your portfolio will then be available through your GitHub Pages URL.
