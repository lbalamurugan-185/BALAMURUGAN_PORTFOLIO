# Balamurugan L, Portfolio
Static site (HTML, CSS, JS). No build step. Deploy on GitHub Pages: Settings → Pages → deploy from `main` / root.

- Edit projects in `js/data.js`. Add `gh:'repo-url'` and `demo:'url'` to a project to set its GitHub and Live Demo buttons (Live Demo only shows when `demo` is set).
- Put your resume at `resume/Balamurugan_L_Resume.pdf`.
- Add a NovaTech screenshot as `images/novatech-dashboard.png` and set `img` for it in `data.js`.
